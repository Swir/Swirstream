# SwirStream AI 0.12.0 for Windows and 0.6.0 for Android

Deep Search now reads TDTChannels and Kodinerds alongside IPTV-org, Free-TV and broadcaster sites. Regional sections in the Spanish catalogue and the country codes in Kodinerds bouquets improve country filtering. The player checks a source separately from finding its address. Public catalogues can include duplicates, off-air stations and geographically restricted streams.

Choose **Import M3U / Dreambox IPTV** to open an Enigma2 IPTV bouquet from your receiver. The importer reads HTTP and HTTPS stream URLs and channel descriptions. Satellite and cable service references without a stream URL require a tuner. Personal sources remain available through the existing source manager. This release omits bulk network checks of portal TXT entries.

## Installation

- **Windows 11 x64** — run the Setup EXE. The first installation fetches the pinned libmpv archive from its upstream publisher and verifies both the archive and the extracted DLL. Existing copies of the matching DLL are reused. To keep a portable library, close the old player, back up its data folder and select that installation directory in Setup.
- **Android 6 or later** — install the APK over the old application. It retains the application ID and signing certificate used by the previous release.

Both applications check GitHub for a newer stable release after the main screen opens. You can also choose **App updates / Aktualizacje programu**. Accept the update to download the platform-specific file. The app checks its size and GitHub SHA-256 digest. Windows runs Setup in the existing directory and relaunches. Android opens its package installer and may ask to allow installs from SwirStream. Existing versions without the updater require this first installation manually.

## Preparing the next stable release

1. Update the Windows project version and the Android version name. Increase Android versionCode. Build and test both signed release assets.
2. Build Windows with windows/build.ps1, then compile windows/ReleaseSetup.iss with Inno Setup 6.7.4. Pass /DPublishDir pointing at the self-contained build directory and /O pointing at the release assets directory.
3. Tag the exact source commit as v followed by the three-part Windows version. Publish the release with tools/publish-release.ps1. Keep the platform-specific naming scheme. Older clients use the public GitHub latest-release API and skip drafts, previews and downgrades. A replacement file with the same platform version does not trigger an update.
