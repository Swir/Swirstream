# Android implementation contract

Native Java package `com.swir.stream`, minSdk 23, compileSdk 36.1, targetSdk 36. Media3 1.11.1. Android first release 0.1.0, based on Windows 0.7.0. No assistant UI. No native Windows libraries.

Shared APIs (agents implement exactly these, additive APIs allowed; notify root):

`Station` (discovery agent): public mutable String fields `id,name,url,country,kind,group,logo,tvgId,userAgent,referrer,origin` default empty; `kind` tv/radio; public long `fetchedAt`; `String key()` stable channel identity, `String sourceKey()` URL identity; `JSONObject toJson()`, `static Station fromJson(JSONObject)`; public no-arg constructor.

`CatalogRepository(Context)` (discovery agent): `List<Station> load()`; `void save(List<Station>)`; `List<Station> scan(Set<String> countries, boolean radio, Progress progress, AtomicBoolean cancelled)` performs actual bounded network discovery, source results merged not partial UI. `Progress.update(String)`; `List<Station> searchWeb(String query, Set<String> countries, Progress, AtomicBoolean)`; `List<FoundPlaylist> playlists()`; `List<Station> importM3u(String text,String source)`; `String exportM3u(List<Station>)`; `List<String> diagnostics()`; `long dataAt()`; `FoundPlaylist` nested class with public String `name,source,text`; public long `fetchedAt`. Cache countries metadata/freshness, previous library retained on network failure. Sources actual iptv-org, radio-browser, Free-TV plus bounded public web search. No browser launch, no invented playable URLs.

`PersonalAi(Context, String profileId)` (AI agent): `String category(Station)` using ported TasteNet weights, explicit categories first; `double score(Station)` preference/source bonus bounded; `void preference(Station,boolean positive)`; `void playback(Station,boolean success,long startupMs)` actual player success/failure only; `boolean enabled()`; `void setEnabled(boolean)`; `int preferenceCount()`; `int sourceCount()`; `void reset()`; all persistent private per-profile files. `void reorder(List<Station>)` deterministic ranking; preserve all candidates. No learning from HTTP success. Include meaningful regression tests.

`ProfileStore(Context)` (AI agent): `List<String> profiles()` profile display names, `String current()` name, `String currentId()` safe folder identifier, `void select(String name)`, `void add(String name)`, `boolean favorite(Station)`, `void setFavorite(Station,boolean)`, `void watched(Station)`, `List<Station> favorites()`, `List<Station> history()`; isolated library per profile. No authentication claim.

`EpgRepository(Context)` (root): `void refresh(Set<String> countries,List<Station> stations, CatalogRepository.Progress progress,AtomicBoolean cancelled)`; `String now(Station)`, `String next(Station)`; `void setSource(String country,String url)` persisted overrides; `long dataAt()`; bounded XMLTV with no external entities; exact/unambiguous mapping; true freshness.

UI/player agent owns `MainActivity.java` and optional `SwirPlayer.java`, layouts/styles UI resources; root owns Gradle, manifests/base resources/icon, tests infrastructure, EpgRepository. UI has startup gate first (cached ready allowed with honest age; initial discovery before main), country multi-select from assets/countries.json, stable filter, TV/radio tabs, favorites/history, sources choice/failover, in-app Media3 PlayerView, quality, refresh/deeper search, found/import/export M3U via SAF, EPG now/next rows, profile/add/enable/reset UI. Pause/release on lifecycle, avoid background accidental playing. Learning actual first rendered frame or progressing audio; 30s real playback preference; no fake proof. Do not execute browser intents for station playback.

Tests: each agent add meaningful plain JUnit (`app/src/test`) where Android mocks unnecessary, or instrumented JUnit4 (`app/src/androidTest`) with AndroidJUnit4. Root coordinates builds/emulator. Avoid running Gradle concurrently. Use JSON via Android instrumentation or org.json test dependency. Instruments cannot be backdoor test receivers in shipped production.

File ownership: discovery owns Station, CatalogRepository and helper parsers/network; AI owns PersonalAi/ProfileStore/TasteNet; UI owns MainActivity/SwirPlayer; root owns remaining scaffold/Epg/build/artifact packaging. Source path app/src/main/java/com/swir/stream. Notify before API contract changes.
